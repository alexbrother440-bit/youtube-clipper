# YouTube Clip Maker

Web app sederhana untuk membuat clip video vertikal 9:16.

## Menjalankan
```bash
pip install -r requirements.txt
python app.py
```

Buka:
http://localhost:10000

Untuk deployment, gunakan platform cloud yang mendukung Docker.

Catatan: gunakan hanya konten yang kamu miliki atau berhak mengunduh/mengedit.
